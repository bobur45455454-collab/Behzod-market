**Ilova:** https://bobur45455454-collab.github.io/Behzod-market/

- Har bir bo‘lim uchun mahsulotlar foto-galereyasi (bo‘limlarni qo‘shish/tahrirlash mumkin)
- Tugagan mahsulotlar o‘chmaydi — “Tugagan” ro‘yxatida saqlanadi
- 🧺 Yukka borish savatchasi: tugaganlar avtomatik tushadi, bozorda ✓ belgilanadi, rasm qilib Telegram’ga ulashiladi
- Takror qo‘shishdan ogohlantirish (oddiy tekshiruv + Gemini AI, o‘z kalitingiz bilan)
- Telefonga ilova sifatida o‘rnatiladi va internetsiz ishlaydi
- Barcha ma’lumot telefonda saqlanadi — “Zaxira olish” bilan nusxa oling
